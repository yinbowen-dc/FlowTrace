# v0.7.0 · Wallet Agent

2026-11-04。新增入口：https://www.darkchunk.win/collect/agent/wallet/

用户通过对话提出转账目标，Agent 调用工具保存任务并执行规则预检。通过后由用户在 Meteor 钱包中确认签名；钱包返回哈希后，服务再比对 FINAL 交易、收据与原始参数。查余额和准备任务也有不经过模型的直接操作入口。

实现复用官方 create-near-app 当前使用的 NEAR Connect 连接方案，保留现有 Node 服务与持久卷。新增原生 NEAR 转账预检，沿用 USDC、USDT、wNEAR 的 FT 预检；MCP 仍为8个只读工具。浏览器独立会话最多20个任务，保留7天。页面关闭后暂停钱包结果轮询，回来可继续核验；已有后台账户观察不受此限制影响。

验证：121项测试通过，覆盖账户与金额约束、NEAR/wNEAR区分、原生与FT精确金额、FINAL证据匹配、查询故障、重复哈希、任务会话隔离及磁盘恢复；本机与服务器 Node 22 均执行。真实主网余额和超限预检已读取，Meteor 连接器显示 Web 与手机扫码入口，390px 手机布局无横向溢出。真实模型已通过工具保存并阻止一笔公开账户示例任务；预发布容器重启后任务保留。

原有观察账户、事件和支付订单已核对保留。未为了测试签名或转移真实资金；真实钱包签名及真实交易后的完整闭环，仍待用户自行验证。换币报价、跨链执行和后台自动签名尚未实现。RPC返回不是独立轻客户端证明。

主流程和技术边界见 [公开指南](../public/agent/wallet/guide.md)，第三方来源见 [SOURCES](../public/agent/wallet/vendor/SOURCES.json)。
