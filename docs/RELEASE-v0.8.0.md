# v0.8.0 · Persistent Agent Sessions & Background Verification

确认事实：v0.7 已有 OpenAI Agents SDK、钱包预检、私有任务 SQLite 和用户钱包入口，但聊天历史只在网页中，交易核验依赖前台轮询。

本次实现：保留现有 SDK，使用原生 Session 管理模型历史，在完整轮次成功后持久化到 SQLite；新增当前讨论任务、详情、重新核验和取消准备任务工具。新增消息请求去重和任务准备去重。会话清空使旧运行失效，不能写回历史或继续创建任务。

关联哈希后，服务器开启有期限的只读核验任务。保存检查租约，支持重启恢复、暂停、续期、退避、额度和到期。后台不调用模型、不签名、不广播。新增1小时有效、可撤销、按会话隔离的任务 MCP 令牌；公共8个链工具不变，私有入口仅提供3个任务读取/核验工具。

推断与取舍：当前单进程服务器继续使用 SQLite 足够容纳演示范围内的状态，未进行高并发容量评估。使用固定任务状态而不引入新的工作流框架，可以复用已有业务验证逻辑。

验证和限制：原生 SDK 会话序列化、HTTP 重试、会话隔离、重启恢复、暂停期间迟到结果、租约、退避、到期和凭证撤销有自动检查；真实模型与浏览器流程另做有限核验。真实钱包签名及真实转账后的完整闭环仍待用户自行验证；不为测试转移资金。换币和跨链执行尚未接入。

完整入口与接口说明：[钱包指南](../public/agent/wallet/guide.md)。

验证结果：136项检查在本机与服务器 Node 22 环境通过；47个运行文件与源码清单一致。真实模型会话跨容器重启后成功继续，重复请求返回缓存结果，3个私有MCP工具及令牌撤销已验证。正式网站刷新后恢复对话与既有任务，390px手机和1280px桌面布局均无横向溢出。静态脚本及样式使用内容哈希版本，避免浏览器加载旧功能。原有观察、支付与钱包任务参数均核对保留。
